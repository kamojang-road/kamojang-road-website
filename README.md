# Kamojang Road Website

Website statis tahap awal untuk KAMOJANG ROAD – Korwil Kampung Melayu.

## File
- `index.html` — isi halaman website
- `style.css` — desain responsif hitam, putih, oranye
- `script.js` — menu navigasi mobile dan tahun footer

## Deploy
Upload ketiga file ini ke root repository GitHub. Untuk Render, buat Static Site dari repository ini dan gunakan:
- Build Command: kosongkan
- Publish Directory: `.`

## Catatan penting
Ini adalah tampilan website publik tahap awal. Login anggota, penyimpanan data anggota, verifikasi KTA, pembayaran, dan inventaris/pemesanan tiket BELUM aktif. Jangan mengumpulkan KTP, kata sandi, bukti pembayaran, atau data pribadi melalui halaman publik ini. Fitur tersebut membutuhkan backend dan kontrol akses yang aman.
